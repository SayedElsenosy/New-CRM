# استخدام Geoapify بدل Google Maps بدون بطاقة بنكية

## ليه Geoapify؟
Geoapify عنده خطة مجانية مع API Key **من غير Credit/Debit Card** تشمل Geocoding لتحديد الأحياء والمدن، وRoute Matrix لحساب مسافات الطرق.
الموقع الرسمي: https://www.geoapify.com/ — تفاصيل الخدمات: https://apidocs.geoapify.com/docs/geocoding/ و https://apidocs.geoapify.com/docs/routing/route-matrix

رصيد الخطة المجانية: **3000 credit/day** مشتركة بين الخدمات، وليست 3000 محادثة. Geocoding عادة 1 credit/طلب. Basic Route Matrix من نقطة واحدة إلى 5 وجهات يُحسب نحو 5 credits وفق المعادلة المنشورة، وقد تزيد التكلفة للخدمات/الخيارات الأخرى. الالتزام بسياسات المزود ونِسب المصدر ضروري.

## إنشاء المفتاح (لا يلزم دفع ولا فيزا)

1. افتح https://myprojects.geoapify.com/ وسجّل حسابًا مجانيًا.
2. أنشئ مشروعًا، ومن صفحة API Keys انسخ المفتاح. **لا تضع المفتاح في رسالة واتساب أو GitHub أو الشات**.
3. في Railway، افتح **خدمة البوت (backend)** ثم Variables وأضف:

```env
GEOAPIFY_API_KEY=YOUR_SECRET_KEY
GEOAPIFY_ROUTES_ENABLED=true
GEOAPIFY_MAX_DAILY_CREDITS=120
GEOAPIFY_MAX_AREA_LOOKUPS_PER_TURN=4
GEOAPIFY_MAX_ROUTE_DESTINATIONS=5
GEOAPIFY_TIMEOUT_MS=2400
```

4. اعمل Redeploy لخدمة البوت. لا تضف متغير يبدأ بـ `VITE_` لأن ذلك قد ينشر المفتاح في المتصفح.
5. اختبر جملة «أنا ساكن في عزبة النخل، أقرب منطقة شغل عندكم إيه؟» بشرط وجود مناطق شغل مفعّلة في المكتب.

## كيف يعمل؟
- **Geoapify هو المزوّد الأول** إذا كان `GEOAPIFY_API_KEY` موجودًا. إذا لم يكن موجودًا يرجع تلقائيًا إلى إعدادات Google Maps القديمة (إن كان مفتاحها موجودًا)، ثم إلى القاموس المحلي المجاني.
- المناطق المعروفة محليًا لا تحتاج طلب Geocoding. المناطق الجديدة تُحلّ بالاسم داخل مصر فقط، ولا يتم إرسال نص المحادثة أو رقم الهاتف للمزوّد.
- يتم تحديد العمل فقط من المناطق **المفعّلة والمؤهلة للمكتب**. المنطقة القريبة ترشيح، وليست منطقة عمل معتمدة تلقائيًا؛ `preferred_work_area` و`geo_qualified` لا يتغيران إلا عند اختيار المتقدم للمنطقة وتأكيده.
- خدمة Route Matrix اختيارية، وتُطلب لأقرب 5 مواقع جغرافية مختلفة فقط؛ وفي حالة فشلها يعود الترتيب للمسافة التقريبية.
- مصدر البيانات يظهر في رسالة واتساب: `Geoapify / © OpenStreetMap contributors`.
- الطلبات تُخزّن نتائجها في الذاكرة فقط لتخفيف الرصيد؛ **الحد اليومي الداخلي تقديري وعلى مستوى عملية Node** ويمكن أن يعاد ضبطه عند إعادة التشغيل أو عبر نسخ متعددة. في الحساب المجاني لا توجد حاجة لتفعيل خطة مدفوعة. راقب الاستهلاك من Geoapify.

## ملاحظات مهمة للدقة والحجم
- أسماء المناطق الواسعة بتحدد مركزًا جغرافيًا تقريبيًا، مش عنوان استلام الطلبات أو موقع العمل الدقيق. أفضل دقة تتطلب إحداثيات مواقع العمل الفعلية.
- الترتيب وفق طرق القيادة وليس وقت المواصلات العامة، ولا يعكس الزحمة الحقيقية. لو المتقدم عايز أسرع وسيلة مواصلات، لازم معلومة إضافية.
- **آلاف المتقدمين يوميًا:** الرصيد المجاني قد ينتهي؛ الحل الأفضل تقليل الاستعلامات المتكررة ومشاركة Cache طويل المدى للمناطق في قاعدة البيانات (بعد مراجعة شروط المزود) أو استضافة مزوّد خرائط مفتوح المصدر بنفسك. **لا تعتمد على Nominatim العام كخدمة إنتاج كثيفة**؛ سياسته بحد أقصى طلب/ثانية وشروط أخرى: https://operations.osmfoundation.org/policies/nominatim/
- الخدمة الحالية لا تختبر مفتاح Geoapify حقيقي تلقائيًا لأن المفتاح لم يتم توفيره في بيئة النشر. اختبارات المشروع تستخدم استجابات وهمية من نفس أشكال API.
